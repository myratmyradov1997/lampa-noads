# Lampa NoAds

Небольшой самостоятельный плагин Lampa, основанный на модуле `MyRatNoAds 1.1.0` из авторских плагинов KinoKrad и Dorama. Он предназначен для **рекламы, которой управляет плеер Lampa**: роликов перед видео и баннеров внутри плеера. Вшитую в видео рекламу и рекламу, которой независимо управляет источник, iframe или другое приложение, он не удаляет.

## Установка

1. Откройте Lampa и перейдите в **Настройки → Плагины** (названия пунктов могут отличаться в разных сборках). Найдите добавление плагина по ссылке.
2. Добавьте адрес JavaScript-файла:

   ```text
   https://myratmyradov1997.github.io/lampa-noads/noads.js
   ```

3. При необходимости включите плагин и **полностью перезапустите Lampa**. Если Lampa работает внутри MSX или другой оболочки, закройте и откройте приложение-оболочку.
4. Запустите видео из привычного источника. Плагин необходимо загрузить отдельно на каждом устройстве. После изменения ссылки или удаления старого плагина перезапустите приложение.

Mac mini не нужен: у автора он просто размещал исходные плагины. Можно разместить `noads.js` на собственном HTTP(S)-сервере и добавить его адрес. По ссылке должен открываться сам JavaScript, а не HTML-страница GitHub. Устройство с Lampa должно иметь доступ к серверу; отдельные сборки ограничивают незащищённый HTTP или междоменные запросы.

## Как это работает

Плагин выполняется внутри JavaScript-среды Lampa; это не блокировщик рекламы для всей сети. При событии плеера `create` он удаляет из данных поля `vast_url` и `vast_banner`, помещает тот же объект в `PlayerPlaylist` и устанавливает `continue_play = true`. В сборке Lampa, которую использовал автор, это воспринимается как продолжение плейлиста: штатный преролл и баннер плеера пропускаются.

Дополнительно плагин оборачивает чтение `XMLHttpRequest.responseText`, **если браузер разрешает переопределить это свойство**. Для адресов `/api/ad/get/preroll` и `/api/ad/get/banner` приложение получает пустой список `{"ad":[]}`; остальные ответы передаются без изменения. Меняется содержимое ответа, которое читает приложение: сам сетевой запрос при этом не обязательно блокируется.

Проверка `window.myrat_lampa_noads` не позволяет установить обработчик повторно. Если в KinoKrad или Dorama уже встроен MyRatNoAds, сработает копия, загруженная первой. Самостоятельный плагин не меняет качество видео и DNS.

## Если реклама осталась

- Сборки и внутренние API Lampa могут меняться. Решение основано на конфигурации, проверенной автором в ноябре 2026 года; работа на каждой версии и каждом устройстве не гарантируется.
- Плагин не убирает рекламу в самом видеопотоке, внешнюю рекламу источника и запросы, которые проходят мимо этих обработчиков (например, через `fetch` вместо XHR).
- Проверьте, что ссылка открывает JavaScript с устройства, плагин включён, а приложение-оболочка полностью перезапущено. Если доступна консоль, найдите `[MyRatNoAds] enabled for all Lampa playback sources`.
- Если модуль уже встроен в другой плагин, он может загрузиться первым. Для поиска конфликта временно отключите дубли. Чтобы отменить изменения, удалите плагин и перезапустите приложение; системные настройки DNS не меняются.
- Если при инициализации `Lampa.Player` ещё недоступен, обработчик не установится. Порядок загрузки плагинов зависит от сборки.

## Свой сервер и проверка

Можно запустить любой статический сервер, например:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

На устройстве в той же сети укажите `http://<локальный-адрес-компьютера>:8000/noads.js`, если сборка Lampa разрешает такой адрес. Этот простой сервер работает без авторизации и TLS; для доступа через интернет используйте подходящий HTTPS-сервер. Для локальной проверки нужен Node.js:

```sh
node --check noads.js
node tests/noads.test.js
```

Тесты имитируют интерфейсы Lampa и не заменяют проверку воспроизведения на реальном телевизоре и конкретной сборке.
